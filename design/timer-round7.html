타이머 시·분·초 다이얼, 버튼 배치, 탭 아이콘

팝업은 모두 실제 크기(폭 320px)로 그렸어요. 다이얼은 휠로 돌아가고, 칩과 시작 버튼은 눌러 볼 수 있어요. 요소별로 섞어 골라도 돼요(예: 배치는 B, 아이콘은 I2-가).

A–D버튼 배치

각 안마다 왼쪽은 알람 탭, 오른쪽은 타이머 탭이에요. 타이머 다이얼은 모두 시 : 분 : 초 세 칸이에요. 아이콘은 비교가 섞이지 않게 I1-가로 통일했어요.

I탭 아이콘

Phosphor 듀오톤 아이콘(옅은 면 + 진한 선)이에요. 위는 크게 본 모양, 아래는 팝업에 들어갈 실제 크기예요. 판정은 아래 실제 크기를 보고 해 주세요.

골라 주실 것

  • 배치: A / B / C / D
  • 아이콘 모양: 가(자명종+모래시계) / 나(자명종+초시계) / 다(종+되감는 시계)
  • 아이콘 표시: I1(아이콘+글자) / I2(아이콘만, 마우스를 올리면 이름)

제 추천: B + I1-가. 이유는 각 안 설명에 적었어요.
