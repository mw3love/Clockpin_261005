# 빠른 타이머 — 실사용 확인 후 크롬 웹스토어 등록 준비

생성: 2026-10-04 13:50

## 배경
- `extension/` 폴더가 MV3 크롬 확장 「빠른 타이머」 첫 버전이다(커밋 `d865de6`). 디자인은 3차 시안까지 거쳐 `R1 · N1+N2 · B1 · M1 · S1` + A3 말랑 민트로 확정됐다. 시안은 `design/timer-round1~3.html`에 있다.
- 헤드리스 크롬으로 대리 확인만 했다(설치, 3초 타이머 종료, 배지 `3s`→`끝`, 알림 생성, 알림 창, 숨은 소리 페이지, 끄기 정리, 일시정지와 +1분, 스톱워치). 테스트 스크립트는 세션 임시 폴더에 있어서 사라졌다. 필요하면 CDP `--remote-debugging-pipe` + `Extensions.loadUnpacked` 방식으로 다시 만든다. 크롬 154는 `--load-extension`이 막혀 있다.
- 사용자는 웹스토어 등록 경험이 있다. 등록 절차 자체는 설명하지 않아도 된다.

## 2026-10-04 추가 (커밋 `84e73b7`)
- 디자인이 바뀌었다. 색은 L1(밝게)·D2(차콜 다크), 맥 설정을 따르고 설정에서 자동/밝게/어둡게. 팝업 다이얼은 끝나는 시각(오전/오후 · 시 · 분)이고, 진행 화면은 R4a(끝나는 시각 크게) + 「+1분 / +5분 / ↶취소」. 시안은 `design/timer-round4.html`.
- 헤드리스 확인 스크립트는 파이썬으로 다시 만들었다(이 PC에는 node 없음). 파이프 연결 + `Extensions.loadUnpacked` + `--enable-unsafe-extension-debugging`. 스크립트는 세션 임시 폴더라 사라졌다.
- 실사용 확인에 "다이얼 손맛(휠 가속·미끄러짐, 드래그)"이 추가됐다. 기준값은 `popup.js`의 `NOTCH_PX=40, FAST_MS=70`, 미끄러짐 최대 5줄.
- 스토어 스크린샷은 새 디자인으로 찍는다. 밝게·어둡게 둘 다 있으면 좋다.
- 5차 시안(`design/timer-round5.html`) 반영: 다이얼 가운데 줄 코랄(H1), 시·분 글자·안내 문구 제거, 설정 버튼 톱니(대칭으로 다시 그림), 설정은 팝업 안 화면으로 옮기고 `options.html`·`options.js`는 삭제(우클릭 「옵션」 줄도 사라짐), 아이콘은 I1 진행 링. 128px는 공식 규칙대로 그림 96px + 여백 16px(확인함).
- 6차 시안(`design/timer-round6.html`) 반영: 다이얼을 돌리면 띠 오른쪽 끝에 「지금 시각으로」 아이콘(시계 + 되돌림)이 나타나고, 누르면 처음 연 상태로 돌아간다(P1 + Z1).
- 칩은 언제나 지금 시각(분) + N분이고 누적하지 않는다. 다이얼 아래 줄은 시계 숫자끼리의 분 차이("10분 후 알림")라, 실제로 울리는 시간은 최대 59초 짧다(초까지 정확한 남은 시간은 링에 나옴). 팝업 탭 이름은 「알람」으로 바꿨다(커밋 `30d9897`). 아직 「타이머」인 곳: 맥 알림 문구·알림 창("오후 2:30 타이머"), 취소 버튼 툴팁, 확장 이름 「빠른 타이머」. 우클릭 「5분 타이머」는 실제로 시간을 재는 기능이라 그대로 두기로 했다. 확장 이름 후보: 빠른 알람 / 툴바 알람 / 딱 그 시각 — 사용자에게 확인.

## 먼저 할 것
1. 사용자에게 실제 맥 크롬에서 써 본 결과를 묻는다. 맥 알림이 실제로 떴는지, 알림음이 들렸는지, 우클릭 메뉴를 눌렀을 때 동작했는지. 이 세 가지는 미검증 상태다.
2. 문제가 있으면 그것부터 고친다. 맥에서 알림 버튼이 「옵션」 안에 숨는지도 확인한다.
